# Task 4: Business Insights Report (EDA)

## Objective
Perform Exploratory Data Analysis (EDA) on a Marketing Campaign Dataset and generate business insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data Understanding
- Missing Value Handling
- Duplicate Check
- Date Conversion
- Statistical Summary
- Income Distribution Analysis
- Product Spending Analysis
- Campaign Acceptance Analysis
- Customer Response Analysis

## Key Insights

### Income Distribution
Most customers belong to the middle-income group.

### Product Spending
Wine and Meat products generate the highest spending.

### Campaign Performance
Campaign 4 received the highest acceptance.

### Customer Response
Most customers did not respond positively to marketing campaigns.

## Conclusion
Marketing efforts should focus on high-spending customer segments and improve campaign targeting to increase response rates.
